# ShotBasket

ShotBasket is a macOS app for collecting screenshots and pasting them as separate file attachments. Screenshots stay on your Mac unless you choose to upload them.

You can connect your own Google Drive, Dropbox, or HTTPS WebDAV destination. Each connection is optional. You can upload selected screenshots manually or turn on automatic uploads for new captures. ShotBasket does not operate a screenshot storage server.

For Google Drive, ShotBasket requests `drive.file` access. It uses that access to create files in a folder you choose, show upload results, and create a public link only when you explicitly request one. It does not read your entire Drive.
